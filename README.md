## Featured Project

### Enterprise AI Assistant

A lightweight Retrieval-Augmented Generation application for answering questions from internal company documents.

The system loads Markdown documents, generates embeddings, performs semantic search, retrieves relevant document chunks, and generates answers using an LLM.

**Tech stack:** Python, FastAPI, Streamlit, AvalAI API, OpenAI SDK, NumPy, Embeddings, Semantic Search

Repository: [Enterprise AI Assistant](https://github.com/parisa69eng/enterprise-ai-assistant)
